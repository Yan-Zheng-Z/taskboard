# Spec Delta

## ADDED Requirements

### Requirement: 设置页
小窗口 SHALL 提供一个设置页，可从标题栏进入和返回。设置页包含：主题（跟随系统、浅色、深色）、始终置顶、开机自动启动、归档显示天数（7、14、30）、整理时读取的对话来源和天数、数据文件位置（可打开所在文件夹）以及版本号和项目地址。每项修改 MUST 立即生效并保存，重新启动后保持；不合法的取值 MUST 被拒绝且原设置不变。

#### Scenario: 切换主题
- **WHEN** 用户在设置页把主题从跟随系统改为深色
- **THEN** 窗口立即变为深色，重新启动后仍是深色

#### Scenario: 关闭始终置顶
- **WHEN** 用户关闭始终置顶
- **THEN** 其他窗口可以盖在小窗口上面

#### Scenario: 开机自动启动
- **WHEN** 用户在设置页打开开机自动启动
- **THEN** 系统的登录项里出现 taskboard，托盘菜单里的同一开关也显示为已打开

#### Scenario: 默认值
- **WHEN** 用户第一次打开设置页
- **THEN** 主题为跟随系统，始终置顶为开，归档显示 7 天，整理读取两个 Agent 最近 7 天的对话

#### Scenario: 数据位置
- **WHEN** 用户点击打开所在文件夹
- **THEN** 系统的文件管理器打开数据文件所在的文件夹

### Requirement: Agent 接入状态
设置页 SHALL 列出 Claude Code 和 DeepSeek Harness，对每一个显示是否在本机检测到，以及 taskboard 的接入说明是未安装、已安装还是需要更新，并提供安装或更新的按钮。只有用户点击该按钮时，小窗口才 MUST 把接入说明写入对应 Agent 的目录；写入失败 MUST 显示原因。

#### Scenario: 尚未安装
- **WHEN** 本机有 Claude Code 但还没有安装 taskboard 的接入说明
- **THEN** 设置页显示 Claude Code 已检测到、接入说明未安装，并有安装按钮

#### Scenario: 一键安装
- **WHEN** 用户点击安装
- **THEN** 接入说明被复制到该 Agent 的目录，状态变为已安装

#### Scenario: 需要更新
- **WHEN** 已安装的接入说明与当前版本的内容不同
- **THEN** 状态显示为需要更新，按钮为更新；点击后变为已安装

#### Scenario: 没有检测到
- **WHEN** 本机没有 DeepSeek Harness
- **THEN** 设置页显示未检测到，仍可安装以备之后使用

## MODIFIED Requirements

### Requirement: 归档页
小窗口 SHALL 提供一个归档页，可从标题栏切换进入和返回。归档页列出最近若干天内完成的任务，天数由设置决定（7、14 或 30，默认 7），按完成时间由近到远排列，每个任务显示编号、名称和完成日期，可以展开查看步骤。完成时间超过该天数的任务 MUST NOT 显示。在归档页把某个步骤改回未完成或添加新步骤时，该任务 SHALL 回到主列表。

#### Scenario: 刚完成的任务
- **WHEN** 用户完成一个任务的最后一步后打开归档页
- **THEN** 该任务出现在归档页最上方，并显示今天的完成日期

#### Scenario: 超过一周
- **WHEN** 归档显示天数为 7，某个任务是 8 天前完成的
- **THEN** 它不在归档页中，但仍在数据文件里

#### Scenario: 调整显示天数
- **WHEN** 用户把归档显示天数改为 30
- **THEN** 8 天前完成的任务出现在归档页中

#### Scenario: 归档为空
- **WHEN** 设定的天数内没有完成任何任务
- **THEN** 归档页说明这段时间没有完成的任务

#### Scenario: 重新打开
- **WHEN** 用户在归档页取消勾选某个任务的一个步骤
- **THEN** 该任务从归档页消失并回到主列表

#### Scenario: Agent 完成任务后自动出现
- **WHEN** 归档页打开时另一个进程完成了某个任务的最后一步
- **THEN** 两秒内该任务出现在归档页
