# Spec Delta

## MODIFIED Requirements

### Requirement: 读不了时不中断
某个来源不存在、某个记录损坏或格式无法识别时，`task digest` MUST 跳过它并继续，在输出末尾说明跳过了什么。"无法识别"包括文件能打开但内容不是该来源的记录格式的情况；记录中个别读不懂的行也 MUST 计数并说明，其余内容照常输出。

#### Scenario: 没装其中一个 Agent
- **WHEN** 本机没有 DeepSeek Harness 的对话目录
- **THEN** 命令照常输出 Claude Code 的对话并成功退出

#### Scenario: 记录格式无法识别
- **WHEN** 某个来源的记录无法解析
- **THEN** 其余对话照常输出，末尾说明该来源有多少个记录被跳过

#### Scenario: 文件内容不是记录
- **WHEN** 对话目录里有一个能打开、但内容完全不是记录格式的文件
- **THEN** 末尾说明该来源有一个记录被跳过，而不是当作没有对话

#### Scenario: 记录里有读不懂的行
- **WHEN** 一个对话记录中间有一行不是合法内容
- **THEN** 该对话的其余消息照常输出，末尾说明有一行没有读出来
