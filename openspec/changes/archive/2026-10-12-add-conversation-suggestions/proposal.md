# Proposal

## Why

现在任务只能手动添加，新装好的 taskboard 打开是一张空列表。而用户要做的事其实已经散落在最近和各个 Agent 的对话里。让 Agent 读一遍最近的对话、归纳出待办并交给用户确认，可以省掉"回忆并逐条录入"这一步；用户也希望平时能直接让 Agent 往列表里加任务。

## What Changes

- 新增 `task digest`：把最近几天 Claude Code 和 DeepSeek Harness 的本地对话记录整理成一份简短摘要（每个对话的所在项目、时间和用户说过的话），供 Agent 阅读。它只读本地文件，不调用任何模型，不联网。
- 新增"任务建议"：Agent 归纳出的任务先作为建议保存，带上来源说明。用户采纳后才成为正式任务，忽略后不会再次出现。对应命令为 `task suggest`、`task suggestions`、`task accept`、`task dismiss`。
- 小窗口新增"建议"区，每条建议可以采纳或忽略。
- 小窗口在第一次启动且列表为空时，显示一张"从最近的对话里整理任务"的卡片。用户点一下开始后，由本机已安装的 Claude Code 在后台完成整理，结果进入建议区。这张卡片只出现一次。
- 更新两个 Agent 的 skill 模板：用户说"整理任务"时走"摘要 → 建议"流程；用户明确要求添加某个任务时直接添加。
- 不包含：定时自动整理、读取其他 Agent 或网页版对话、由小窗口直接调用模型接口。

关于"第一次启动自动整理"：用户的原话是自动整理一次。这里设计成卡片上点一下才开始，而不是静默运行，因为这一步会把对话摘要发给模型并消耗额度，对其他安装这个开源项目的人来说不应在未告知的情况下发生。

## Capabilities

### New Capabilities

- `conversation-digest`: 从本机的 Agent 对话记录生成供 Agent 阅读的简短摘要，包括范围、内容取舍、大小上限和读不了时的行为。
- `task-suggestions`: 任务建议的数据、生命周期（提出、采纳、忽略、去重）以及对应的命令。

### Modified Capabilities

- `desktop-widget`: 新增建议区，以及第一次启动时的整理卡片。
- `agent-integration`: 新增"从对话整理任务"和"按用户要求直接添加任务"两条约定。

## Impact

- `src/core/`：数据文件新增可选的建议和首次引导字段，旧数据无需迁移；新增读取对话记录的模块。
- `src/cli/`：新增五个子命令。
- `src/widget/`：新增建议区和首次引导卡片；主进程新增一次"在后台启动 Claude Code"的调用。
- `integrations/` 下两个 skill 模板和 `docs/agent-integration.md`。
- 隐私：`task digest` 的输出包含用户在对话里说过的话。它只在用户或 Agent 运行该命令时产生，并会进入运行它的那个 Agent 的上下文，也就是发给该 Agent 背后的模型服务商。默认同时包含两个 Agent 的对话，因此一个服务商会看到用户与另一个 Agent 的对话摘要；提供参数限定来源，并在文档中写明。
- 依赖两个 Agent 未公开承诺稳定的本地记录格式，它们升级后可能读不出来，届时该来源会被跳过并提示。
- 第一次启动的后台整理只支持 Claude Code；没有安装时卡片改为提示用户对自己的 Agent 说一句话。
