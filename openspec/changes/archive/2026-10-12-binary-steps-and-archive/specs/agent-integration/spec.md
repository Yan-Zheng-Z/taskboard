# Spec Delta

## MODIFIED Requirements

### Requirement: 按用户要求直接添加任务
接入说明 SHALL 规定：用户明确说出要添加的任务时，Agent 用 `task add` 连同步骤直接创建，不经过建议区，并在回复里说明新任务的编号。用户没有给出步骤时，Agent SHALL 用一个与任务同名的步骤创建，而不是替用户拆分步骤。

#### Scenario: 用户说"加一个任务"
- **WHEN** 用户说"加一个任务：周五前交报销单，分成填表和找发票两步"
- **THEN** Agent 创建带截止日期和两个步骤的正式任务，并告诉用户任务编号

#### Scenario: 用户没有说步骤
- **WHEN** 用户说"加一个任务：给房东打电话"
- **THEN** Agent 创建一个只有"给房东打电话"这一个步骤的任务

### Requirement: 接入说明覆盖常见请求
接入说明 SHALL 说明以下情况的做法：步骤只有完成和未完成，一个步骤确实做完后才标为完成；署名记录在哪些操作上；如何用列表输出判断哪个任务最紧急；如何修改任务的名称和截止日期；任务的所有步骤完成后会自动归档，不需要也不能手动归档。

#### Scenario: 指定的任务没有步骤
- **WHEN** 用户指定的任务只有一个与任务同名的步骤，而当前工作只完成了其中一部分
- **THEN** Agent 不把这个步骤标为完成；用户希望细分时，Agent 按用户说的添加步骤

#### Scenario: 步骤只做了一部分
- **WHEN** 用户说"现在做任务 2，做完一步就更新进度"，Agent 把步骤 1 做了一半
- **THEN** Agent 不把步骤 1 标为完成，并在回复里说明进展

#### Scenario: 询问最紧急的任务
- **WHEN** 用户问"我的任务里哪个最急"
- **THEN** Agent 根据列表输出里的紧急程度回答，不需要自己计算日期

#### Scenario: 修改截止日期
- **WHEN** 用户说"任务 1 的截止日期改到下周三"
- **THEN** Agent 用说明里给出的命令修改该任务的截止日期

#### Scenario: 完成最后一步
- **WHEN** Agent 完成了任务的最后一个未完成步骤
- **THEN** Agent 告诉用户该任务已完成并归档，不再执行其他归档操作
