# Spec Delta

## ADDED Requirements

### Requirement: 建议区
存在待处理的建议时，小窗口 SHALL 在任务列表上方显示建议区，每条建议显示名称、截止日期、步骤及其中哪些已完成、来源说明和提出者，并提供"采纳"和"忽略"。没有建议时 MUST 不显示建议区。

#### Scenario: 采纳一条建议
- **WHEN** 用户点击某条建议的"采纳"
- **THEN** 该建议从建议区消失，任务列表里出现对应的任务及其步骤

#### Scenario: 忽略一条建议
- **WHEN** 用户点击某条建议的"忽略"
- **THEN** 该建议从建议区消失，任务列表不变

#### Scenario: Agent 提出建议后自动出现
- **WHEN** 窗口打开时另一个进程运行 `task suggest`
- **THEN** 两秒内建议区出现这条建议，无需用户操作

#### Scenario: 没有建议
- **WHEN** 没有待处理的建议
- **THEN** 窗口里没有建议区

### Requirement: 第一次启动的整理卡片
当从未显示过整理卡片、且没有任何任务和建议时，小窗口 SHALL 显示一张卡片，说明可以从最近的 Agent 对话里整理出任务建议，以及这会把对话摘要发给模型并消耗额度，并提供"开始整理"和"以后再说"。无论用户选择哪个，这张卡片 MUST 不再自动出现。

#### Scenario: 第一次启动
- **WHEN** 用户第一次启动小窗口，没有任何任务
- **THEN** 窗口显示整理卡片

#### Scenario: 选择以后再说
- **WHEN** 用户点击"以后再说"后重新启动小窗口
- **THEN** 卡片不再出现，窗口显示普通的空状态

#### Scenario: 已有任务的用户
- **WHEN** 已经有任务的用户升级后启动小窗口
- **THEN** 不显示整理卡片

### Requirement: 后台整理
用户点击"开始整理"后，小窗口 SHALL 在后台启动本机的 Claude Code 完成一次整理，期间显示正在进行的状态且窗口保持可用；完成后显示结果是新增了多少条建议，失败时显示原因。未安装 Claude Code 时，卡片 MUST 改为告诉用户可以对自己的 Agent 说哪句话来整理。

#### Scenario: 整理成功
- **WHEN** 后台整理完成并提出了三条建议
- **THEN** 建议区出现这三条建议，窗口说明新增了三条建议

#### Scenario: 没有可整理的内容
- **WHEN** 后台整理完成但没有提出任何建议
- **THEN** 窗口说明没有从最近的对话里找到待办事项

#### Scenario: 未安装 Claude Code
- **WHEN** 本机找不到 Claude Code
- **THEN** 卡片不提供"开始整理"，而是显示可以对 Agent 说的那句话

#### Scenario: 整理失败
- **WHEN** 后台进程出错或超过时间上限
- **THEN** 窗口显示失败原因，任务和建议数据不受影响
