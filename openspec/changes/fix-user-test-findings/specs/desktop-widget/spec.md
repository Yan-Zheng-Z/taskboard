# Spec Delta

## ADDED Requirements

### Requirement: 显示真实编号
小窗口 SHALL 显示每个任务的编号和每个步骤的编号，且 MUST 与命令行使用的编号相同，不得用列表中的位置代替。收起后的窄栏同样显示任务编号。

#### Scenario: 删除过步骤的任务
- **WHEN** 某任务的步骤编号是 1、3、4（编号 2 已被删除）
- **THEN** 窗口里这三个步骤显示的编号是 1、3、4

#### Scenario: 任务编号
- **WHEN** 列表按截止日期排序后，编号为 5 的任务排在第一位
- **THEN** 它显示的任务编号是 5

### Requirement: 空白名称提示
在窗口里提交只含空格的任务名称或步骤名称时，小窗口 MUST 不提交并提示名称不能为空。

#### Scenario: 只输入空格
- **WHEN** 用户在添加任务的名称框里只输入空格并提交
- **THEN** 表单没有提交，窗口提示名称不能只有空格

### Requirement: 完成后保持可见
用户在展开的任务里把它的最后一步完成、使该任务移到列表的已完成部分时，小窗口 SHALL 让这个任务保持展开并滚动到可见位置。

#### Scenario: 完成最后一步
- **WHEN** 用户在一个展开的任务里完成它唯一未完成的步骤
- **THEN** 该任务移到已完成部分后仍然展开，并在窗口的可见区域内
