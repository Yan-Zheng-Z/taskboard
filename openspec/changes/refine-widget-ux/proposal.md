# Proposal

## Why

小窗口常驻置顶，却只有一种大小，一直挡着一块屏幕；删除、忽略和采纳一旦点错无法挽回，其中"忽略"还会让同名建议永久不再出现；现有配色用了多种彩色边框和虚线框，显得杂乱。

## What Changes

- 新增紧凑模式：窗口可以收成一条窄栏，只显示最近到期的未完成任务及其进度和截止情况，点一下恢复原来的大小。收起状态在重启后保留。
- 新增撤销：删除任务、删除步骤、忽略建议、采纳建议之后，窗口给出几秒钟的"撤销"。撤销只还原这一次操作，不影响期间 Agent 或命令行做的其他修改。
- 重新设计配色和版式：中性色为主、一种强调色、去掉彩色侧边和虚线框、次要操作改为不抢眼的文字按钮，紧迫程度仍然同时用文字表达。
- 不包含：已完成任务的归档、建议采纳前编辑、把建议并入已有任务、命令行的撤销。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-widget`: 新增紧凑模式和撤销两项要求。配色和版式调整不改变规格层面的行为。

## Impact

- `src/widget/`：窗口大小切换、撤销所需的窗口接口、渲染和样式。
- `src/core/model.js`：新增把被删除的任务、步骤和被忽略的建议放回原位的操作。
- `widget.json` 增加"是否收起"字段，旧文件无需迁移。
- README 的截图和小窗口说明需要更新。
